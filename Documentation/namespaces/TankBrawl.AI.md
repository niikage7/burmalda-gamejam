Боты: навигация A* по центрам клеток, «мозг» бота — FSM (патруль, поиск, атака с кружением, таран, отступление, удержание точки, уворот, поиск по кустам), выбор цели по стоимости, обзор размером с экран игрока; уровни сложности (`DifficultyConfig`). Характер — в `BotProfile`. См. [Боты](../articles/bots.md).
