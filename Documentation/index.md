## Как собрать этот сайт

Нужен только .NET SDK 10 (DocFX ставится локально из `dotnet-tools.json`, Unity не нужна).

```sh
./Documentation/build.sh --serve     # Linux / macOS
Documentation\build.cmd --serve      # Windows
```

Сайт откроется на <http://localhost:8080>, статические файлы лежат в `Documentation/_site`.
Без `--serve` сайт только собирается. Как писать комментарии, чтобы они попадали сюда, — в статье
[Как писать документацию](articles/writing-docs.md).
