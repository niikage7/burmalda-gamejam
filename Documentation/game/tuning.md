# Как настраивать игру

Эта страница — для геймдизайнеров и всех, кто хочет поменять числа в игре без программирования.

## Где живут числа

Все настраиваемые числа игры — скорость, урон, перезарядка, поведение ботов — лежат не в коде, а в отдельных
**файлах настроек** (в Unity они называются *ScriptableObject*-ассетами). Их открывают в Unity и правят в окне
**Inspector** (инспектор), как обычную форму с полями.

| Файл настроек | Где лежит | Что настраивает |
| --- | --- | --- |
| `PlayerTankConfig` | `Assets/_Project/ScriptableObjects/Tank/` | Танк игрока: скорость, разгон, разворот, здоровье |
| `BotTankConfig` | там же | То же для ботов (сейчас медленнее игрока: 2,6 против 2,8) |
| `DummyTankConfig` | там же | Неподвижные мишени на тестовой арене (500 здоровья) |
| `NitroConfig` | там же | Нитро и таран — общий для всех танков |
| `ArmorPiercing` | `Assets/_Project/ScriptableObjects/Weapons/` | Снаряд игрока: скорость, урон, перезарядка, размер |
| `BotWeapon` | там же | Снаряд ботов |
| `DefaultBotProfile` | `Assets/_Project/ScriptableObjects/Bots/` | Характер бота: реакция, меткость, дистанции, когда таранить |

Полный список всех полей с описанием — на странице [Параметры в инспекторе](../articles/inspector.md).
Описания там на английском (они же видны всплывающей подсказкой в Unity, если навести мышь на поле).

## Как поменять число

1. В окне **Project** найдите файл настроек (пути — в таблице выше).
2. Кликните по нему — справа в окне **Inspector** появятся его поля.
3. Поменяйте число. Наведите мышь на название поля — появится подсказка, что оно значит.
4. Нажмите **Play** и проверьте, как ощущается.

> [!TIP]
> Числа в файлах настроек можно менять **прямо во время игры (в Play Mode)** — эффект виден сразу, и изменения
> **сохраняются** после остановки. Это удобно для подбора, но не забывайте вернуть значение, если эксперимент не удался.
> А вот изменения объектов на сцене во время Play Mode после остановки пропадают.

> [!WARNING]
> Файлы настроек общие для всей команды. Если поменяли число и хотите его оставить — скажите тому, кто отвечает за
> эту часть игры, и внесите итоговое значение в документ баланса `tank_balance_v0_2.md`.

## «Хочу, чтобы…» — что крутить

| Хочу, чтобы… | Файл | Поле |
| --- | --- | --- |
| танк ездил быстрее | `PlayerTankConfig` | `moveSpeed` |
| танк резче разгонялся / тормозил | `PlayerTankConfig` | `acceleration` / `deceleration` |
| танк быстрее разворачивался | `PlayerTankConfig` | `rotationSpeed` (градусов в секунду) |
| лёгкое касание стика не трогало танк с места | `PlayerTankConfig` | `driveThreshold` (больше — дольше только поворот) |
| танк был живучее | `PlayerTankConfig` | `maxHealth` |
| игрок стрелял чаще | `ArmorPiercing` | `fireInterval` (меньше — чаще) |
| снаряды летели быстрее / медленнее | `ArmorPiercing`, `BotWeapon` | `speed` |
| снаряды били сильнее | `ArmorPiercing`, `BotWeapon` | `damage` |
| снаряд легче попадал по танкам | `ArmorPiercing`, `BotWeapon` | `tankHitRadius` |
| снаряд не цеплялся за углы | `ArmorPiercing`, `BotWeapon` | `wallHitRadius` (меньше — реже цепляет) |
| снаряд отскакивал от стали больше раз | `ArmorPiercing`, `BotWeapon` | `maxBounces` |
| нитро хватало надольше | `NitroConfig` | `capacity` (секунды) |
| нитро быстрее восстанавливалось | `NitroConfig` | `regenPerSecond` |
| таран был слабее | `NitroConfig` | `ramDamage` или `ramCooldown` (больше — реже) |
| таран отбрасывал дальше | `NitroConfig` | `knockbackSpeed`, `knockbackDuration` |
| боты стреляли точнее | `DefaultBotProfile` | `aimSpreadDegrees` (меньше — точнее), `leadFactor` (больше — лучше упреждение) |
| боты медленнее реагировали | `DefaultBotProfile` | `reactionDelayMin`, `reactionDelayMax` |
| боты стреляли с большего расстояния | `DefaultBotProfile` | `fireRange` |
| боты не подъезжали вплотную | `DefaultBotProfile` | `stopDistance` |
| боты чаще таранили | `DefaultBotProfile` | `nitroRamDistance` (0 — никогда) |

Чтобы сделать бота с другим характером, скопируйте `DefaultBotProfile` (`Ctrl+D`), поменяйте числа и назначьте
новый профиль нужному боту. Подробнее — в [Рецептах](../articles/recipes.md#новый-характер-бота).

## Настройки карты

Время восстановления кирпича, его прочность и мигание настраиваются не в файле, а на объекте `Bricks` в сцене
(компонент *Destructible Tilemap*): поля `restoreDelay`, `brickDurability`, `warningDuration`.
