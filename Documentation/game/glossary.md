# Словарь терминов

Слова, которые встречаются в документации и в разговорах команды.

## Игровые

| Термин | Что значит |
| --- | --- |
| **Арена** | Карта, на которой идёт бой |
| **Бот** | Танк под управлением компьютера. Бывают вражеские и союзные |
| **Матч** | Один бой на одной арене, от начала до экрана итогов |
| **Режим** | Правила матча: «Команда на команду», «Удержание точки», «Все против всех» |
| **Раунд** | Часть матча в «Команде на команду»: до уничтожения одной из команд. Матч — до трёх выигранных раундов |
| **База** | Угол карты, где появляются танки команды. Её не разрушают — это просто место появления |
| **Точка, зона** | Круг в центре карты в режиме «Удержание точки». Очки идут команде, которая стоит в нём одна |
| **Держатель** | Бот, который в режиме «Удержание точки» стоит в зоне, а не гоняется за врагами |
| **Возрождение, респавн** | Возвращение погибшего танка на карту через несколько секунд |
| **Спавн-защита** | Неуязвимость на 2–3 секунды после появления на карте, танк медленно мигает |
| **Дополнительное время** | Продолжение матча после конца времени, если счёт равный, — до первого перевеса |
| **Доп. цель** | Второе условие матча за +20 шестерёнок: например, «5 уничтожений» |
| **HP, здоровье** | Сколько урона танк выдержит. У базового танка — 100 |
| **Урон** | Сколько здоровья отнимает попадание |
| **Перезарядка, кулдаун** | Пауза после выстрела (или другого действия), прежде чем его можно повторить |
| **Бронебойный снаряд** | Основной снаряд игрока: сильный удар по одной цели, отскакивает от стали |
| **Осколочный снаряд** | Второй снаряд игрока: слабее, но взрывается и задевает врагов вокруг |
| **Нитро** | Временное ускорение, запас которого восстанавливается сам |
| **Таран** | Удар корпусом на нитро: отнимает здоровье у врага и ломает кирпич |
| **Рикошет** | Отскок снаряда от стальной стены |
| **Неуязвимость** | Короткое время (0,3 с) после попадания, когда танк не получает урон |
| **Усиление, павер-ап, пикап** | Бонус на карте, который действует несколько секунд: скорострельность, взрывные снаряды, лазер, щит |
| **Лазер** | Усиление: вместо пушки непрерывный луч, бьёт всех врагов на линии |
| **Щит** | Усиление: поглощает одно любое попадание |
| **Киллтаб** | Список «кто кого уничтожил» в правом верхнем углу экрана |
| **HUD** | Всё, что нарисовано поверх боя: счёт, часы, здоровье, нитро, киллтаб |
| **Шестерёнки** | Игровая валюта для улучшений между матчами |
| **Мастерская, улучшения** | Экран меню, где за шестерёнки покупаются постоянные улучшения танка |
| **Ранг угрозы** | Сумма всех купленных уровней улучшений. Чем он выше, тем сильнее боты |
| **D, «диаметр танка»** | Единица расстояния в балансе: 1D — ширина танка. «Скорость 2,8D/с» — танк за секунду проезжает почти три своих ширины |
| **Хитбокс** | Невидимая зона, по которой игра считает попадание. У снаряда их два: побольше для танков, поменьше для стен |
| **Упреждение** | Прицеливание с поправкой на движение цели — стрельба «туда, где враг будет» |
| **Уворот** | Манёвр бота в сторону от летящего в него снаряда |

## Технические (Unity)

| Термин | Что значит |
| --- | --- |
| **Unity** | Игровой движок, в котором делается игра |
| **Сцена** | Отдельный «уровень» или экран в Unity: меню, арена, тестовая арена |
| **Песочница** | Тестовая сцена, где каждый проверяет свою часть игры, не мешая остальным. В игре — «Настройки → Отладка» |
| **Play Mode** | Режим запуска игры прямо в редакторе Unity (кнопка Play) |
| **Инспектор** | Окно Unity, где видны и редактируются свойства выбранного объекта или файла |
| **Префаб** | Заготовка объекта (например, танка), которую можно расставлять на сценах много раз |
| **ScriptableObject, конфиг** | Файл с настройками (числами), который правится в инспекторе без программирования |
| **Тайлмап** | Карта, собранная из одинаковых квадратных клеток-тайлов, как из плитки |
| **Автотайл** | Клетка стены, которая сама подбирает рисунок по соседям, чтобы стена выглядела цельной |
| **Компонент** | «Деталь» объекта в Unity, отвечающая за одно умение: ездить, стрелять, получать урон |
| **Скин** | Набор рисунков танка одного цвета |
| **Безопасная зона (safe area)** | Часть экрана телефона без выреза камеры и закруглённых углов; кнопки ставятся внутри неё |
| **APK** | Файл установки игры на Android |
| **FSM, состояния бота** | Способ описать поведение бота как набор режимов («патрулирует», «атакует», «отступает») и правил перехода между ними |
| **A\* (А-стар)** | Алгоритм поиска кратчайшего пути по лабиринту. Им боты находят дорогу |
| **Заглушка, плейсхолдер** | Временный рисунок или звук, который заменят настоящим |
