# Управление

В игре всего четыре действия: **ехать/поворачивать**, **стрелять**, **нитро** и **сменить тип снаряда**.

## Клавиатура и мышь (в редакторе и на компьютере)

| Действие | Клавиши |
| --- | --- |
| Ехать и поворачивать | `W` `A` `S` `D` или стрелки |
| Стрелять | `Пробел` или левая кнопка мыши |
| Нитро | Левый `Shift` (держать) |
| Сменить тип снаряда | `Q` |
| Выйти в меню / выйти из игры | `Esc` |

## Геймпад

| Действие | Кнопка |
| --- | --- |
| Ехать и поворачивать | Левый стик |
| Стрелять | Нижняя кнопка (A на Xbox, ✕ на PlayStation) или правый курок |
| Нитро | Правая кнопка (B / ◯) или левый курок |
| Сменить тип снаряда | Верхняя кнопка (Y / △) |

## Телефон

> [!NOTE]
> Экранного управления **пока нет** — это следующий этап работы. Ниже описано, как оно будет устроено.

- **Слева** — виртуальный стик для езды.
- **Справа** — большая кнопка выстрела, рядом с ней кнопка нитро.
- **Над кнопкой выстрела, у края экрана** — маленькая кнопка смены снаряда.
- **Внизу по центру** — полупрозрачный таймер действующего усиления.
- Кнопка «Назад» на Android работает так же, как `Esc`.

## Как танк слушается стика

Это главное, к чему нужно привыкнуть:

1. **Слегка отклонили стик** (или коротко нажали направление) — танк **разворачивается на месте**, не трогаясь.
   Так удобно прицеливаться: пушка смотрит туда же, куда корпус.
2. **Отклонили стик сильно** — танк **едет** в эту сторону.
3. **Резко потянули стик в сторону или назад** — танк сначала быстро развернётся (это занимает доли секунды),
   а потом поедет. Задним ходом танк не ездит — он всегда разворачивается.
4. **Отпустили стик** — танк быстро тормозит.

Нитро работает, только пока танк **едет** и кнопка зажата. Если просто стоять с зажатым нитро, запас не тратится.
