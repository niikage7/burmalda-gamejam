Я сделал git fetch. Ничего не меняй и не делай merge/pull сам.
1. git log --oneline HEAD..origin/main — кто и что закоммитил.
2. git diff --stat HEAD...origin/main — какие файлы затронуты.
3. git status — мои незакоммиченные правки.
Коротко по-русски: что нового по смыслу, какие общие файлы поменялись
(интерфейсы, конфиги, ProjectSettings, Packages, .inputactions, сцены),
где возможен конфликт с моими правками и что мне нужно учесть в своей части.
