# Арт окружения в стиле танков — готов к встраиванию

Единый мультяшный стиль по образцу танков: плоская заливка в 2–3 тона, почти чёрный контур ~2 px,
у стен и кустов светлая верхняя и тёмная лицевая (южная) грань, вода утоплена (видна стенка берега).
Все тайлы 64×64 = 1 клетка = 1 юнит (64 px/юнит, как у танков в `layout.json`).

## Что внутри

| Папка | Что | Файлов |
| --- | --- | --- |
| `incoming_art/tiles` | Кирпич `brick_blob_NNN.png` | 47 |
| `incoming_art/brick_damaged` | Повреждённый кирпич `brick_damaged_blob_NNN.png` | 47 |
| `incoming_art/Steel` | Сталь `steel_NNN.png` | 47 |
| `incoming_art/Water` | Вода `water_NNN.png` | 47 |
| `incoming_art/Bush` | Кусты `bush_NNN.png` (тело 88 %, контур 97 % непрозрачности) | 47 |
| `incoming_art/Ground` | Трава: `grass_light_0..2`, `grass_dark_0..2`, `grass_background_128` | 7 |
| `incoming_art/tank_sprites` | Танки — без изменений, образец стиля | 4 × 9 |
| `Unity/Assets` | Скрипты для Unity (см. ниже) | 2 |
| `preview` | Демо-сцена и листы всех тайлов | 7 |
| `_generator` | Генератор и проверки (Python) | 6 |

`NNN` — маска соседей (стандартный 47-тайловый blob-набор): N=1, NE=2, E=4, SE=8, S=16, SW=32, W=64, NW=128;
диагональ учитывается, только если есть оба соседних кардинальных соседа.
Имена и папки совпадают с исходным `incoming_art` — файлы можно просто заменить.

## Встраивание в Unity

1. Скопируйте содержимое `incoming_art` поверх вашей папки с артом в `Assets`
   (одноимённые PNG заменятся, `.meta` и ссылки сохранятся).
2. Скопируйте `Unity/Assets/Scripts/Tiles/SiblingRuleTile.cs` и `Unity/Assets/Editor/AutoTileBuilder.cs` в `Assets`.
   Если в проекте уже есть `AutoTileBuilder.cs` из прошлого архива — замените его (иначе будет два класса с одним именем).
3. Нужен пакет **2D Tilemap Extras** (`com.unity.2d.tilemap.extras`) — он входит в 2D-шаблон.
4. Меню **Tools → Tiles → Build Rule Tiles**. Скрипт найдёт наборы по именам файлов в любой папке `Assets` и:
   - выставит импорт: Sprite, 64 px/юнит, Bilinear, без сжатия и мипмапов, Alpha Is Transparency;
   - создаст рядом с картинками `Brick_RuleTile`, `BrickDamaged_RuleTile`, `Steel_RuleTile`, `Water_RuleTile`, `Bush_RuleTile`;
   - создаст Tile-ассеты травы `grass_*_Tile` для палитры;
   - для `grass_background_128` выставит Wrap Mode = Repeat и Mesh Type = Full Rect (фон одним спрайтом, Draw Mode = Tiled).
   Запускать можно повторно — ассеты обновляются на месте.
5. Перетащите Rule Tile в Tile Palette и рисуйте — нужный вариант подбирается по соседям сам.

### Коллайдеры
Кирпич, повреждённый кирпич, сталь и вода — `Grid` (квадрат на клетку: предсказуемый рикошет,
ровное слияние через CompositeCollider2D). Кусты — без коллайдера. Поменять можно в инспекторе Rule Tile
или в массиве `Sets` в `AutoTileBuilder.cs`.

### Повреждённый кирпич
`Brick_RuleTile` и `BrickDamaged_RuleTile` — это `SiblingRuleTile`: они считают друг друга «своими» соседями,
поэтому повреждённый кирпич встаёт в любую клетку стены без контура и ступенек. Замена в коде:

```csharp
tilemap.SetTile(cell, brickDamagedTile);   // соседи пересчитаются сами
```

### Трава
`grass_light_*` и `grass_dark_*` — два близких тона для шахматки; `_0` — ровный, `_1` и `_2` — с пучками травы
для разнообразия. Либо один спрайт `grass_background_128` (шахматка 2×2) с Draw Mode = Tiled.

### Кусты и «танк в кустах»
Кусты уже полупрозрачные. Для эффекта «игрок спрятался» можно дополнительно снижать прозрачность
Tilemap кустов, пока танк внутри: `bushTilemap.color = new Color(1, 1, 1, 0.5f)`.

### Если видны тонкие линии между тайлами
Сложите спрайты тайлов в Sprite Atlas (Padding 4) или включите Pixel Snap у камеры/материала.
У полностью прозрачных пикселей тайлов цвет залит цветом края — тёмной каймы при фильтрации нет.

## Проверено

- Комплектность и формат: 5 × 47 тайлов 64×64 RGBA + 7 файлов травы; имена как в исходном `incoming_art`.
- Края без соседа полностью прозрачны — ничего не обрезается по границе клетки.
- Стыки: каждый тайл сравнён с картой, нарисованной целиком (`qa_world.py`): кирпич, повреждённый кирпич,
  сталь — точное совпадение; кусты ≤ 2/255; вода ≤ 14/255 (на глаз неразличимо).
  Быстрая проверка на ~16 000 случайных стыков на набор, включая целый + повреждённый кирпич вперемешку, — без замечаний.
- Трава повторяется без шва.
- Unity-скрипты: компилируются (проверено компилятором C# против заглушек API Tilemap Extras/UnityEditor);
  правила Rule Tile: на 20 000 случайных окрестностей каждой клетке подходит ровно одно правило нужного тайла.
  В самом Unity скрипты не запускались — первую сборку проверьте по консоли.

## Перегенерация и проверки (Python 3, numpy, scipy, Pillow)

```bash
cd _generator
python3 gen2.py out                                  # все наборы → out/ (≈1–2 мин), тот же результат байт в байт
python3 gen2.py out Bush Water                       # только выбранные: tiles brick_damaged Steel Water Bush Ground
python3 qa.py ../incoming_art                        # быстрая проверка
python3 qa_world.py ../incoming_art                  # строгая проверка стыков
python3 preview_scene.py ../incoming_art scene.png   # демо-сцена с танками
```

Палитры — словари `BR` (кирпич), `ST` (сталь), `WA` (вода), `BU` (кусты), `GR` (трава) в `gen2.py`.
